# Team Hat Trick (1985 Bally Sente) — Arcade Edition

A faithful browser recreation of the classic 1985 Bally Sente arcade hockey game **Hat Trick**, expanded to a 3v3 format (*Team Hat Trick*) with dual control schemes, authentic physics, synthesized CEM3394 audio, scanline CRT effects, and modern HD sprite enhancements.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16.0.0 or later)

### Running the Server

Start the built-in, zero-dependency Node server:

```bash
npm start
```

Or run directly with Node:

```bash
node server.js
```

Then open your browser to [http://localhost:3000](http://localhost:3000).

### Environment Options

You can customize the port and host via environment variables:

```bash
PORT=8080 HOST=0.0.0.0 npm start
```

### Development with Auto-Reload

Node 18+ provides built-in file watching:

```bash
npm run dev
```
